# KAI

Videojuego de exploración, supervivencia e investigación científica creado por Simóncio.

## Concepto

Un gas desconocido comienza a salir desde el subsuelo y altera el entorno. El jugador interpreta a un científico que debe explorar una zona generada proceduralmente, recoger muestras, analizar pistas y descubrir qué está provocando el fenómeno.

## Tecnología

- Godot 4.6
- GDScript
- Generación procedural mediante código
- Sin assets externos obligatorios para ejecutar el prototipo

## Controles

WASD: movimiento
E: interactuar
