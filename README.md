# KAI

Videojuego de exploración e investigación científica creado por Simóncio.

## Concepto

KAI ocurre principalmente bajo tierra. Un fenómeno desconocido aparece en una enorme red de túneles y cavernas. El jugador es un científico que debe explorar, recoger muestras, seguir las lecturas del detector y descubrir el origen del fenómeno.

## Versión actual: v0.3

- Mundo subterráneo procedural
- Túneles y cámaras generados por código
- Rocas y cristales luminosos
- Zona de gas KAI
- Estación de investigación subterránea
- Muestras coleccionables
- Cámara FPS
- Linterna con sombras
- HUD de profundidad, gas y exposición
- Atmósfera oscura con niebla y luz ambiental

## Tecnología

- Godot 4.6
- GDScript
- Generación procedural mediante código
- Sin assets externos obligatorios para ejecutar el prototipo

## Controles

WASD: movimiento
SHIFT: correr
F: encender/apagar linterna
ESC: liberar/capturar mouse
